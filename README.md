# 💸 SettleUp

A terminal app that splits group trip expenses and finds the fewest
payments needed to settle everyone.

## How it works
1. Work out each person's net balance (paid minus fair share).
2. Repeatedly match the biggest debtor with the biggest creditor.
3. Print the result as simple "X pays Y" tickets.

## Run
    python settleup.py

Requires Python 3.6+. No external libraries needed.
